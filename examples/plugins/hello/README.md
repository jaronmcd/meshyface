# Hello plugin

This plugin package is the copyable example for Meshyface **Scripts (Alpha)**. It is
not bundled or discovered from this repository location.

Copy the whole `hello` directory into the path configured by
`--plugins-directory`, enable the runtime and the `hello` plugin, then restart
Meshyface. Send `!hello` to receive a sender-specific visit count.

See [`docs/plugins.md`](../../../docs/plugins.md) for the one-restart install
flow, trust model, configuration, and troubleshooting.
